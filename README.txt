# Yash Legal Media Website

## Files
- `index.html` — complete website
- `style.css` — complete styling
- `logo.jpg` — Yash Legal Media logo
- `akku-pandit.jpg` — Akku Pandit creator photo
- `advocate.jpg` — Advocate section photo

There is intentionally **no images folder**. All images are in the same directory as `index.html`, so the project can be uploaded directly to GitHub Pages.

## GitHub Pages
1. Upload all files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save.

The website uses relative image paths and does not require a server-side backend.
